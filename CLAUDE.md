# Language rules

Follow [AGENTS.md](AGENTS.md) for every user-facing response and every English text change. Use ASD-STE100 Issue 9 as the authority. Apply its writing rules and controlled dictionary. Check each changed sentence before delivery. Preserve exact code, identifiers, citations, numbers, and required quotations. Do not claim full compliance without a human check against the official standard.

# Line endings

Follow the line-ending rules in [AGENTS.md](AGENTS.md), `.gitattributes`, and `.editorconfig`.
Use LF for text files. Use CRLF for Windows command files (`.bat` and `.cmd`).
