## Chrome Energy Saver evidence and remaining limits

Chrome has its own Energy Saver behavior, distinct from the Windows battery-saver API flag. [Google's official Chrome guidance](https://support.google.com/chrome/answer/12929150?hl=en) describes reduced image capture/background activity on battery under the selected Energy Saver setting, and says it does not engage while plugged in. Chromium also registers a separate browser battery-saver preference in [its current source](https://chromium.googlesource.com/chromium/src/+/main/components/performance_manager/user_tuning/prefs.cc). That source is contextual; it is not an observed preference snapshot from installed Chrome152.

None of these harnesses changes Chrome's Energy Saver preference or supplies an explicit Energy Saver override. The retained owned launch command lines contain background-timer/occluded-window/renderer-backgrounding switches; those switches do not report Energy Saver's actual state. Historical browser `Local State`/preference snapshots were not saved with the failed run, and the owned temporary profiles underwent normal browser cleanup. No unrelated user profile or browser setting was inspected or modified. **Historical Chrome Energy Saver state is unavailable**, as is native window/GL state at the failed run's onset. A Windows battery-saver-off observation in a later control cannot fill that gap.

The [power-event comparison](capture-power-comparison.md) records earlier DC state and AC becoming online during the failed full run. White capture started before AC and persisted afterward. Power history and browser power scheduling remain possible confounds; neither establishes the white capture's cause. Source review finds no application30 Hz or1 Hz limiter in the shared main animation loop: it draws once for every delivered rAF callback, and CameraTracker also schedules via rAF. All three controls share that code and the same clean-output path. Native/compositor scheduling and browser power behavior require actual correlated failure evidence before attribution.
